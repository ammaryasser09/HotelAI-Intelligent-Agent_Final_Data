# HotelAI — النسخة النضيفة (Nile Pearl Hotel)

دي النسخة اللي الفريق كله هيشتغل عليها من دلوقتي. فيها كل اللي هتستخدموه، ومفيهاش أي حاجة زيادة.
الفندق والداتا وهميين، ومعمولين على شكل فندق 5 نجوم حقيقي في القاهرة.
**"النهارده" في الداتا = 19 سبتمبر 2026.**

## فيها إيه

| الفولدر | فيه إيه | مين هيستخدمه |
|---|---|---|
| `database/` | داتابيز PostgreSQL جاهزة: الجداول (23)، والداتا، والاستعلامات اللي الـ API محتاجها، والاختبارات، والـ ERD، وقاموس البيانات | Backend، System Analysis |
| `knowledge_base/` | 44 ملف فيهم كل معلومات وسياسات وأسعار الفندق، والـ agent بيجاوب منهم | فريق الـ RAG |
| `rag/` | الملفات متقطعة chunks، و3,996 سؤال وإجابة بالـ 5 لغات | فريق الـ RAG |
| `app/` | كود البحث والبرومبت والـ tools، والـ prototype (صوت ← رد بصوت) | RAG، Speech |
| `evaluation/` | 200 سؤال مصري واقعي، و630 محادثة، وملف مراجعة المصري | الكل |
| `docs/` | قواعد الفندق، ومين بيجاوب على أنهي سؤال | الكل |
| `scripts/` | `build_rag.py` و`check_data.py` | فريق الـ RAG |
| `static/` | صور الأوض (`rooms/`: نيل وسيتي لكل نوع) وصور الفندق (`hotel/`)، والمسارات متسجلة في `room_types.image_nile` و`image_city` | Backend، Frontend |

## ابدأ منين

**الداتابيز (الأسهل بـ Docker):**
```bash
cd database
docker compose up -d            # PostgreSQL 16 والداتا كلها بتتحمّل لوحدها أول مرة
```
الطرق التانية (PostgreSQL متسطب، أو pgAdmin) في `database/README.md`.

**الـ RAG:**
```bash
python -m app.rag.evaluate --mode bm25                  # من غير إنترنت
pip install -r requirements.txt
python -m app.rag.evaluate --mode hybrid                # مع BGE-M3
python -m app.rag.demo "الفطار بكام؟" --show-prompt
```

**الـ API (FastAPI):** الخطوات كاملة في `docs/API_SETUP.md`
```powershell
pip install -r requirements-api.txt
Copy-Item .env.example .env          # وحط فيه باسورد PostgreSQL والـ JWT_SECRET بتوعك
uvicorn app.api.main:app --reload     # http://127.0.0.1:8000/docs
pytest                                # كل الاختبارات لازم تعدّي
```

**بعد أي تعديل في `knowledge_base/` أو `rag/hotel_faq_gold.csv`:**
```bash
python scripts/build_rag.py      # يعيد بناء الـ chunks والـ FAQ index
python scripts/check_data.py     # لازم يطلع 10/10
```

## تحديث v8 — الداتا النهائية

دي النسخة اللي بنعتبرها **final**: أي تعديل بعد كده يبقى لفيتشر جديدة بس.
- **التيكتات في جدول واحد:** `complaint_tickets` و`special_requests` اندمجوا في `customer_requests` (الداتابيز بقت 23 جدول). الشكوى `Complaint` والطلب الخاص `Special Request`، والنوع القديم بقى في عمود `category`. وفيه أعمدة جديدة: `handled_by` (الموظف اللي ماسك التيكت)، و`resolved_at`، و`call_id` (المكالمة اللي اتفتح فيها). والطلب الخاص بقى ليه قرار (`decision`) من الموظف زي طلب الخصم.
- **التيكتات القديمة اللي كانت مفتوحة من شهور اتقفلت:** المفتوح دلوقتي بس اللي لسه ينفع يتعمل: من آخر 14 يوم، أو خدمة لإقامة جاية أو شغالة. خدمة الإقامة (هاوس كيبينج، روم سيرفس، طلب خاص...) بتخلص مع الإقامة.
- **الزائر:** التيكت محتاج لوجين، إلا الطوارئ (`Emergency`) والـ `Staff Callback`: دول بيتفتحوا من غير عميل ومربوطين بالمكالمة.
- **`calls.account_id`** بدل `identity_verified`: مين اللي بيكلم (NULL = زائر).
- **check-in وcheck-out:** متسجلين لكل إقامة خلصت، ولكل نزيل موجود في الفندق وصل قبل النهارده (وصول النهارده لسه ماعملوش check-in). و`rooms.status = Occupied` بقى معناها إن في نزيل عامل check-in دلوقتي.
- **الخصم:** على السعر المرن بس؛ الـ Non-refundable مايتحطش عليه خصم (الداتابيز بترفض). `check_availability` بقى بيحسب خصم الإقامة الطويلة 12% أو الكود (الأكبر) ويرجّع المبلغ بعد الخصم. والـ router بيبعت `account_id` للكود الشخصي.
- **داتا تجريبية ماشية مع بعض:** 17 مكالمة (`calls`، `call_messages`، `call_actions`) بين 14 و19 سبتمبر: حجز جديد بخصم الإقامة الطويلة (B020001)، وحجز بكود شخصي (B020002)، و4 طلبات خصم (2 اتوافق عليهم بكود شخصي DC030 وDC031، وواحد اترفض، وواحد مستني الأدمن)، وطوارئ طبية وحريق، وتحويل لموظف شات لايف، وStaff Callback، وصيانة، وطلب خاص، وشكوى، وربط حجز من شركة سياحة، ومكالمة اتقفلت.
- **المحادثات (لسه 630):** الطوارئ الطبية والحريق بقى فيها أرقام الطوارئ والاستقبال وتنبيه الفريق، والسرقة فيها رقم الشرطة، والتحويل لموظف بقى شات لايف. واتضاف flow للزائر اللي بيتطلب منه لوجين (`INT012_F6_visitor_login`) وflow لطلب الخصم (`INT027_F2_discount_request`)، 5 لكل واحد.
- **الحسابات في الـ KB:** `reservation_security.txt` بقى فيه إزاي تعمل حساب، ونسيان الباسورد، والطوارئ من غير لوجين، ومعاهم 15 سؤال FAQ جديد بالـ 5 لغات (intent `INT034`).
- **الـ 200 سؤال:** 22 سؤال شكوى أو طلب بقى بيسألهم ضيف عامل لوجين (إقامته ماشية مع السؤال)، والطوارئ فضلت للزائر.
- **الاختبارات:** `run_checks.sql` بقى 39 فحص، و`constraint_checks.sql` بقى 16.

## تحديث أكتوبر 2026

- **الـ login بدل رقم الحجز والاسم:** الإيجنت بقى بياخد الحجز من حساب الضيف ويتأكد منه، ومابقاش يسأل عن رقم الحجز والاسم الأخير. الحجز اللي اتعمل بالتليفون أو من شركة سياحة أو موقع حجز بيتضاف للحساب برقم الحجز والاسم الأخير أو آخر 4 أرقام في التليفون. والزائر بياخد إجابات عامة بس. اتعدل `router.py`، و`agent.py` (`login`/`logout`)، و`test_agent.py`، والـ 630 محادثة والـ 200 سؤال (عمود جديد `account_id`)، واتعمل حساب لـ 5 ضيوف كانوا محتاجينه.
- **الدفع بقى بالعربون:** في السعر المرن الضيف بيدفع أول ليلة بس أونلاين كعربون من لينك دفع، والباقي في الفندق. لو لغى قبل الوصول بـ 48 ساعة العربون بيرجع كله، ولو بعد كده أو ماجاش العربون مش بيرجع ومفيش حاجة تانية بتتخصم. السعر اللي مش قابل للاسترداد زي ما هو. اتعدل في الـ KB، والـ FAQ بالـ 5 لغات، وجدول `payments`، و`run_checks.sql`، والـ tools، والـ evaluation.
- **مهلة الدفع:** الحجز الجديد بيبقى `Pending` (الأوضة محجوزة) لحد ما لينك الدفع يتدفع: 24 ساعة، أو ساعتين لو الوصول بعد أقل من 24 ساعة. لو اتدفع بيبقى `Confirmed`، ولو لأ بيتلغي لوحده والدفع بيبقى `Expired`. فيه عمود جديد `payments.payment_due_at`، والمهلتين في `app_settings`، والاستعلامات في `queries.sql` (4، 4b، 4c).
- **الحسابات:** جدول `user_accounts` لكل اللي بيدخلوا (ضيف، موظف، أدمن)، و`booking_links` للحجز اللي اتعمل برة والضيف ضافه لحسابه. الضيف اللي عامل لوجين بيشوف حجوزاته على طول (`my_bookings`)، والحجز اللي من برة بيتضاف مرة واحدة برقم الحجز واسم العيلة أو آخر 4 أرقام (`link_booking`). باسورد الديمو للكل `NilePearl@2026`.
- **تعديل الحجز:** الإيجنت بيعدّل بنفسه بعد ما يشوف المتاح (`quote_modification` وquery 9). التواريخ الجديدة والليالي الزيادة بنفس سعر الليلة المتفق عليه، وتغيير نوع الأوضة بالسعر الأساسي للنوع الجديد. حجوزات Booking.com بتتعدل من عندهم.
- **الخصومات:** الإيجنت مابيطبقش غير خصم الإقامة الطويلة (7 ليالي أو أكتر) أو كود صالح، الأكبر فيهم. أي خصم تاني بيبقى `Discount Request` والأدمن يقرر.
- **الاسترداد:** العربون بيرجع أوتوماتيك من بوابة الدفع لما الإلغاء يكون في الميعاد.
- **الموظفين:** check-in وcheck-out وتسجيل باقي الحساب من الداشبورد (query 8، وعمودين `checked_in_at` و`checked_out_at`).
- **التحويل لموظف والطوارئ:** الإيجنت مابيحولش لموظف غير لو الضيف عنده مشكلة وطلب ده، والتحويل بيبقى شات لايف، ولو مفيش موظف فاضي بيتفتح تيكت `Staff Callback` مستعجل. وفي الطوارئ الإيجنت بيدي الأرقام (الإسعاف 123، الشرطة 122، المطافي 180) ويفتح تيكت `Emergency` بأولوية Critical. الطلبات بقى ليها عمود `priority` وtool `create_request`.
- **العنوان:** إجابات "الفندق فين" بقى فيها العنوان كامل (14 شارع كورنيش النيل، جاردن سيتي) بدل "القاهرة، مصر" بس.
- **الصور:** فولدر `static/` جديد فيه صور الأوض والفندق، و`room_types` بقى فيه عمودين `image_nile` و`image_city`، وجدول `hotel_photos` بيربط صور الفندق بالأماكن (البيسين، السبا، الجيم...) وtool جديد `hotel_photos`.
- **الصيانة:** نوع طلب جديد `Maintenance` (تكييف، نور، حنفية...).
- **الخصم على الحجز:** `bookings` بقى فيه الخصم اللي اتطبق (`discount_source`، `discount_code_id`، `discount_amount`) و`amount_due` = الإجمالي بعد الخصم. خصم واحد بس: الإقامة الطويلة أو الكود، الأكبر.
- **طلب الخصم:** الأدمن بيوافق أو يرفض (`customer_requests.decision`)، ولو وافق بيتعمل كود شخصي للضيف ده بس ولمرة واحدة (`discount_codes.customer_id`) ويتبعتله بالإيميل (`queries.sql` رقم 11).
- **أكواد التحقق:** جدول `verification_codes` لتأكيد الإيميل ونسيان الباسورد (`queries.sql` رقم 12).
- **الإعدادات:** `deposit_nights` (العربون كام ليلة)، و`otp_valid_minutes` و`otp_max_attempts`.

## إيه اللي اتغير عن HotelAI_v4

- **الحجوزات اللي ملهاش أوضة (3,468) اتشالت** هي واللي مربوط بيها. دلوقتي كل حجز مؤكد أو خلص ليه أوضة فعلاً، والداتابيز نفسها بترفض أي حجزين على نفس الأوضة في نفس الليلة.
- **الأوض بقت برقمها** اللي الضيف بيسمعه (زي 1307)، بدل كود داخلي.
- **العملاء:** تاريخ التسجيل بقى قبل أول إقامة، وكل اللي حاجزين سنهم 18 أو أكتر.
- **الشكاوى والطلبات الخاصة والتقييمات:** الكلام بقى ماشي مع النوع، يعني شكوى "Room Issue" مبقتش بتقول "Unexpected charge".
- **اتشال:** الداتا الخام، والتقارير، والسكريبتات القديمة، وملفات الـ fine-tuning، والأرشيف. لو حد احتاج تاريخ أي تعديل، هو موجود في HotelAI_v4.
